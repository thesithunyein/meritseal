# Security policy

Report vulnerabilities privately through GitHub's **Security → Report a vulnerability** if private reporting is available. If it is unavailable, request a private contact channel in an issue without posting vulnerability details.

Include affected versions, expected and observed behavior, and steps using sample data. Keep credentials and real applicant data out of reports. Keep `AGENT_GAMES_HMAC_SECRET` server-side. The browser receipt checksum provides no issuer authentication.
